## Поток данных (Data Flow)

```
Raw Sources (JSON/ZIP/SQLite)
         |
    [Adapter Layer]  smellai_datasets/{rminer,swe_refactor}.py
         |
         +---> [MLflow Path]  mlflow_utils/datasets/ -> workflows/*_workflow.py -> MLflow DB
         |
         +---> [HF Path]  hf_datasets/converter.py -> preprocessor.py -> chain_builder.py
                                                    -> mlflow_bridge.py -> MLflow DB
```

## Стандартный формат записи (MLflow GenAI)

```python
{
    "inputs": {...},        # Входные данные для LLM
    "expectations": {...},  # Ground truth для evaluation
    "tags": {...}           # Метаданные (repo, commit, status)
}
```

## Ключевые паттерны проектирования

1. **Adapter** — единый интерфейс `Dataset` для разных источников
2. **Factory** — `DatasetFactory` для создания MLflow datasets
3. **Lazy imports** — `rminer/__init__.py` использует `__getattr__` для избежания circular deps
4. **Result objects** — `CompileResult(success, error_summary)` для обработки ошибок
