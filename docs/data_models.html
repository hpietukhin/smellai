SmellAction

swe_refactor/persistence/models.py · line 16

String enum used as the action field on SmellEvent to record the lifecycle transition of a smell instance.

Enum 
class SmellAction(str, Enum):
    DETECTED  = "detected"   # found in current iteration
    RESOLVED  = "resolved"   # completely removed
    CREATED   = "created"    # introduced by refactoring
    PERSISTED = "persisted"  # still exists (may have changed)

Lifecycle flow

Smell first appears → DETECTED
Refactoring eliminates it → RESOLVED
Refactoring introduces it → CREATED
Still present next iteration → PERSISTED

Two-layer design
Per-source DataFrames hold raw source-specific rows (no Pydantic overhead). Only at the evaluation boundary are rows promoted to EvalSample. Analytics persistence (SmellEvent, RefactoringAttempt, etc.) is a parallel write path from the LangGraph agent — separate from both LangGraph checkpoints and MLflow tracking.
