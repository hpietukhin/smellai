Big picture

MLflow’s role in the system

1. Evaluation tracking

Workflows run mlflow.genai.evaluate(...) to execute agents over records and produce scored runs visible in MLflow.

2. Dataset management

Unified EvalSample records are converted to MLflow GenAI format and stored as datasets.

3. Operational support

Helpers start the MLflow UI, configure the tracking URI, and create experiments automatically.

Dependencies & configuration

How MLflow is configured

  • HTTP tracking URI often defaults to http://localhost:5000

Relevant files: pyproject.toml README.md mlflow.db mlflow_utils/auto_server.py mlflow_utils/server.py
Data contract

Everything centers on EvalSample

Canonical shape

EvalSample( source, sample_id, inputs, expectations, tags, )

Defined in smellai_datasets/schema.py

Why it exists

  • inputs: what gets passed to the agent predict_fn
  • expectations: ground truth for scorers
  • tags: metadata for filtering and grouping
  • Shape mirrors the MLflow GenAI evaluate contract
Bridge layer: smellai_datasets/mlflow_bridge.py - samples_to_mlflow_records(samples) - samples_to_mlflow_df(samples)
Evaluation workflows

Where MLflow runs happen

Unified workflow

workflows/eval_workflow.py

  • Supports both rminer and swe
  • Loads samples
  • Converts to MLflow records
  • Calls mlflow.genai.evaluate(...)

Specialized workflows

  • workflows/rminer_eval_workflow.py
  • workflows/swe_eval_workflow.py
  • workflows/common.py contains shared MLflow setup + result printing
Core pattern: records = samples_to_mlflow_records(samples) setup_workflow_mlflow(tracking_uri, experiment) results = mlflow.genai.evaluate( data=records, predict_fn=predict_fn, scorers=scorers, )

File: mlflow_utils/datasets/manager.py

Registration flow

  1. Set tracking URI
  2. Find or create experiment
  3. Create dataset via mlflow.genai.datasets.create_dataset
  4. Call dataset.merge_records(records)
MLflow dataset APIs used: - search_datasets - get_dataset - create_dataset
RMiner dataset creation

Dedicated dataset creation script

rminer/create_rminer_dataset.py

  • Builds GenAI records from manifest data
  • Can enrich records with SonarQube issues
  • Creates an MLflow dataset and merges records

Dataset-level tags

  • source
  • total_pairs
  • total_hunks
  • total_refactorings
Key calls: mlflow.set_tracking_uri(args.tracking_uri) mlflow.set_experiment(args.experiment) dataset = create_dataset(...) dataset.merge_records(records)
Infrastructure

Local MLflow server and UI management

mlflow_utils/server.py

  • Checks if port is already in use
  • Starts mlflow ui
  • Waits until HTTP endpoint is reachable
  • Writes logs to mlflow_ui.log

mlflow_utils/auto_server.py

  • Parses tracking URI
  • Auto-starts local server for http://localhost:5000-style URIs
  • Calls mlflow.set_tracking_uri
  • Optionally sets experiment name
MLflow UI command used: mlflow ui --backend-store-uri sqlite:///mlflow.db --port 5000 --host 0.0.0.0

Reality check

What the code does vs what the docs say

Implemented in code

  • mlflow.genai.evaluate(...)
  • mlflow.genai.datasets.*
  • mlflow.set_tracking_uri(...)
  • mlflow.set_experiment(...)

Documented / aspirational

  • mlflow.langchain.autolog()
  • mlflow.log_metrics(...)
  • Automatic LangGraph tracing in architecture docs

Important: I found the tracing/autolog pattern in docs, but not wired into active repo code.

Stale or mismatched pieces

MLflow-related inconsistencies to know about

README path drift

README references scripts/create_rminer_dataset.py, while the actual script present is rminer/create_rminer_dataset.py.

CLI / runner drift

mlflow_utils/runner.py references methods and paths that appear stale relative to current code.

Old bridge references

Some scripts refer to older bridge functions not matching current samples_to_mlflow_records APIs.

So: the core MLflow workflows are real, but some helper scripts look partially outdated.

Commands

How you use MLflow in practice here

Open the UI

mlflow ui --backend-store-uri sqlite:///mlflow.db

Run RMiner evaluation

uv run workflows/rminer_eval_workflow.py \ --manifest rminer_data/manifest.json \ --experiment rminer-evaluation

Run SWE evaluation

uv run workflows/swe_eval_workflow.py \ --dataset /path/to/pure_refactoring_data.json \ --experiment swe-refactor-evaluation

Create dataset

uv run rminer/create_rminer_dataset.py \ --manifest rminer_data/manifest.json \ --tracking-uri sqlite:///mlflow.db
